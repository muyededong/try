# 坦克大战 (Tank Battle)

一个纯 HTML + Canvas 的经典坦克大战游戏，无需任何依赖，打开 `index.html` 即可游玩。

## 玩法

- 控制你的坦克，保护底部的**基地（老鹰）**，消灭所有敌方坦克。
- 每关有固定数量的敌人，最多同时出现 4 个。
- 砖墙可被子弹摧毁，钢墙无法摧毁，水会阻挡坦克但子弹可穿过，树会遮挡视野。

## 操作

| 操作 | 按键 |
|------|------|
| 移动 | `WASD` / 方向键 |
| 射击 | `空格` / `J` |
| 暂停 | `P` |

## 运行

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
# 使用 Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 特性

- 🎨 像素风格 Canvas 渲染，多关卡地图
- 🔊 Web Audio 音效（射击 / 爆炸 / 过关）
- 🧱 砖墙、钢墙、水域、树林、基地等多种地形
- 💥 粒子爆炸特效
- 🎮 得分、生命、剩余敌人 HUD
